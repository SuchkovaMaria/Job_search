# Курсовая работа №2.Трекер самолетов.

## Описание:

Данный проект разрабатывался в рамках курсовой работы и содержит следующий функционал:
1. Класс по определению самолетов в указанной области (стране);
2. Класс по определению информации по самолетам из указанной области (страны);
3. Класс для записи информации по самолетам и обработке записанных данных;
4. Функцию сортировки списка самолетов по высотам;
5. Функцию фильтрации списка самолетов по высоте; 
6. Функцию фильтрации списка самолетов по стране.


## Установка:

1. Клонируйте репозиторий
   (`git clone`) [GitHub]()
2. Установите зависимости
   (`pip requirements.txt`)

## Использование:

1. Откройте проект.
2. Введите данные, запрашиваемые функциями.
